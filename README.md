Meridia National Statistics — an original static statistics portal for the fictional country Meridia. No dependencies or build step. Overview, economy, population, labour, prices and regions pages with hand-drawn SVG charts, sortable tables, a working search and a phone layout, all sharing one invented 2015–2025 dataset whose provincial figures sum to the national totals.

## Run it

```sh
node serve.ts --port 8080
```

Then open http://localhost:8080. To rebuild the deterministic dossier:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
